## Publicar

1. Crear un repositorio vacío en GitHub (por ejemplo `viaje-vietnam-2026`).
2. `git remote add origin https://github.com/<usuario>/viaje-vietnam-2026.git`
3. `git push -u origin main`
4. En **Settings → Pages**, elegir la rama `main` y la carpeta `/ (root)`.
